# Clinical OS — Admin panel

Vite app for **SUPER_ADMIN** and **ADMIN**.

```bash
# API must be on :3001
npm install
npm run dev
```

Open http://localhost:5173  

Default login: `superadmin@clinicalos.local` / `SuperAdmin123!`

Super Admin can set medicine **boost_score** and **search_rank** on the Drug KB page — that order drives `GET /medicines/search`.
